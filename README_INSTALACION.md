# Instalar DeltaBalance (Linux)

1. Descomprimí el archivo.
2. Abrí una terminal en la carpeta que se creó.
3. Corré: `bash install.sh`
4. Abrí DeltaBalance desde el menú de aplicaciones.

No hace falta contraseña de administrador: se instala solo para tu usuario.

## Actualizar a una versión nueva

Descomprimí la versión nueva y corré `bash install.sh` otra vez. Tus datos no se tocan.

## Desinstalar

En la misma carpeta, corré: `bash uninstall.sh`

Tus datos no se borran: si lo volvés a instalar, siguen ahí.
